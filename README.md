# イヅミ設計 コーポレートサイト デザイン初稿

ワイヤーフレーム機能台本をもとに制作した、静的な提案用プロトタイプです。

## 確認方法

`index.html` をブラウザで開くか、このフォルダでローカルサーバーを起動してください。

```sh
python3 -m http.server 8080
```

## 初稿時点の扱い

- 写真はすべて仮素材です。画面上にも `PLACEHOLDER PHOTO` と表示しています。
- 実績名、実績データ、会社情報、採用情報、数値、問い合わせ先は仮内容です。
- お問い合わせフォームは入力確認まで動作しますが、送信先には接続していません。
- 採用エントリーは仮のメールリンクです。
- 正式公開前に、写真の利用条件確認と正式素材への差し替えを行ってください。

## 主な操作

- 固定ヘッダーとスマートフォン用メニュー
- 実績カテゴリー絞り込み
- 実績詳細ダイアログ
- SOLUTIONS と FAQ の開閉
- 採用数値のカウントアップ
- お問い合わせフォームの必須チェックと入力確認

## ファイル構成

- `index.html` ページ本体
- `assets/style.css` レイアウトとデザイン
- `assets/main.js` 操作とアニメーション
- `assets/images/` 仮写真
