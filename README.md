# イヅミ設計 コーポレートサイト デザイン初稿

ワイヤーフレーム機能台本をもとに、梓設計の公式サイトに見られる「建築写真を主役にした大きなファーストビュー」「余白のある白基調」「大きな日本語コピー」を参考に制作した静的な提案用プロトタイプです。コピーやレイアウトを複製したものではなく、イヅミ設計向けに再構成しています。

## 確認方法

`index.html` をブラウザで開くか、このフォルダでローカルサーバーを起動してください。

```sh
python3 -m http.server 8080
```

## 初稿時点の扱い

- 写真はすべて仮素材です。画面上にも `PLACEHOLDER PHOTO` と表示しています。
- 実績名、実績データ、会社情報、採用情報、数値、問い合わせ先は仮内容です。
- お問い合わせと採用導線は仮のメールリンクです。
- 正式公開前に、写真の利用条件確認と正式素材への差し替えを行ってください。

## 主な操作

- 写真が切り替わるファーストビュー
- スクロール後の固定ヘッダーとスマートフォン用メニュー
- 実績カテゴリー絞り込み
- 実績詳細ダイアログ

## ファイル構成

- `index.html` ページ本体
- `assets/style.css` レイアウトとデザイン
- `assets/main.js` 操作とアニメーション
- `assets/images/` 仮写真
